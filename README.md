# Resume Builder

A modern Resume Builder web application that allows users to create, customize, preview, and download professional resumes with ease.

🌐 Live Demo

Frontend: Resume Builder Live Demo

##  Features
* Create professional resumes
* Add personal details, education, skills, and experience
* Live resume preview
* Edit and update resumes anytime
* Download resumes
* Responsive design for desktop and mobile devices
* Simple and user-friendly interface

##  Tech Stack

### Frontend
* React.js
* React Router DOM
* Bootstrap
* Axios
* React Toastify

### Backend
* Node.js
* JSON Server

##  Backend Setup

This project uses **JSON Server** as a mock backend instead of a traditional database.

### Install Dependencies
```bash
npm install
```

### Run Backend Server
```bash
node index.js
```

Server runs on:

```bash
http://localhost:3000
```
##  Frontend Setup
### Install Dependencies
```bash
npm install
```
### Run Frontend
```bash
npm run dev
```

Frontend runs on:
```bash
http://localhost:5173
```

##  API Storage
Resume data is stored inside:
```bash
db.json
```
JSON Server automatically handles CRUD operations without requiring MongoDB or any other database.
